Official league & club channels

The only binding injury status is the league's Game Status Report at nfl.com/injuries. Each club's website and social handle below is parsed from that club's own nfl.com team page — the league-published social directory — never typed from memory. A row whose page could not be fetched is marked “probe pending”; no handle is ever guessed to fill a gap.

National NFL insiders

Reporters whose injury news routinely breaks league-wide. Names are seeded in collectors/directory_seed.json (a reviewable, diff-able file) and every Bluesky account below is re-checked each day against the public Bluesky AppView: verified means an exact name match and a valid Bluesky verification; review means the name matches but the platform checkmark is absent; X offers no free verification API in 2026, so every X link is an explicit one-click manual check.

Beat writers (per club)

These are the writers actually named in the live ESPN injury feed on player status updates (name, outlet and club exactly as printed, grouped by the clubs whose players they report on). We assert no social handles for them: each row gives exact-name search deep links (X and Google News) plus the ESPN player pages they were quoted on, so a human can confirm the genuine account before following. Writers with fewer than two attributed updates are omitted.

Known impostors, mirrors & fraud warnings

Accounts that come up when searching for the reporters above but are not them. Bluesky's own moderation labels and self-described “mirror / bot / parody” accounts are listed here precisely so nobody mistakes them for a source. They are never linked as official anywhere on this site.
