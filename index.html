The designation shown is the official nfl.com value whenever nfl.com publishes one; only the league's Game Status Report is binding. Published by the league: nfl.com/injuries
inferred* means nfl.com printed no Game Status for that player (they practised without a designation), so the value shown is derived from the practice line rather than published by the league. Inferred values are never used as ground truth when checking one source against another.

    Reporter accuracy scorecard

    Forward-collected. A claim is scored against the official nfl.com designation for the same club and player: correct when the availability class matches, wrong when it does not, unverifiable when no official record exists. A score is only published after 5 resolved claims, and the headline figure is the Wilson lower bound, not the raw ratio.
